# Numerical Evidence Without Physical Hardware

The arm can be validated mathematically before the physical mechanism exists. This evidence is deliberately limited to the ideal rigid-link model.

Run:

```bash
python tools/numerical_validation.py
```

The generated `artifacts/numerical_validation.json` contains four evidence groups:

1. **FK → IK → FK reconstruction** — checks that reachable poses generated by forward kinematics can be recovered by the analytic inverse model and reconstructed consistently.
2. **Angle sensitivity** — perturbs each ideal joint by a small angular amount and measures the resulting Cartesian endpoint displacement.
3. **Sampled workspace envelope** — reports X/Y/Z bounds, horizontal radius, and shoulder-to-endpoint distance over explicit sampled joint ranges.
4. **Position Jacobian characterization** — samples the absolute determinant of the Cartesian position Jacobian to expose how kinematic conditioning changes across the modeled workspace.

Default sampled joint ranges are:

```text
base:      -90° .. 90°
shoulder:  -30° .. 120°
elbow:    -135° .. -5°
```

The Jacobian report includes minimum, p05, median, p95, and maximum absolute determinant plus the fraction of samples below a documented relative near-singularity threshold.

## What this proves

These results can support statements such as:

> The analytic 3-DOF model was evaluated over the documented deterministic joint grid, including FK/IK reconstruction, sampled workspace geometry, angle sensitivity, and Jacobian conditioning.

## What this does not prove

It does not measure or predict, by itself:

- MG996R positioning accuracy;
- backlash or horn play;
- printed-part flex;
- calibration error;
- payload deflection;
- collision clearance;
- real joint limits;
- physical repeatability.

Those remain gated by the physical endpoint experiment protocol in `docs/PHYSICAL_VALIDATION.md`.
